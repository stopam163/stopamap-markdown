## [0.1.0] - 2026-11-15

### Added

- Source-mapped `MarkdownLiveDocument` with LF normalization and line index.
- Block ranges, content ranges, blank-run lookup, and next-content navigation.
- Block parser for headings, paragraphs, nested lists, task lists, quotes, fenced code, tables, rules, images, and YAML front matter.
- Inline parser for emphasis, bold-italic, strikethrough, code, underline, highlight, superscript, subscript, links, images, and hard breaks.
- Reference links, shortcut references, and footnotes.
- Outline extraction and word/character/line counting.
- Cross-platform CI and xUnit test suite.
